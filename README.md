# mundo-musical-bacilos
Universo musical interactivo inspirado en Bacilos, desarrollado en p5.js.

**Recordar es vivir — Memorias en estéreo**
Mariana Cuello · Isabella Tobón · Sara Serpa — Pensamiento Algorítmico, Uniandes.

## Cómo verlo
Abrir `index.html` con un servidor local (por ejemplo, Live Server en VS Code) o publicar el repositorio con GitHub Pages.
Si se abre directo con doble clic, el navegador bloquea la carga de la música y las fotos.

## Carpetas
- `sketch.js`: el código
- `fotos/`: las fotos de cada escena
- `musica/`: fragmentos de 40 segundos de cada canción

## Música
Fragmentos de canciones de Bacilos usados solo con fines académicos. Los derechos son de sus autores.
